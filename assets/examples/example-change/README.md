# Example Change

This directory is a **read-only example** and does not participate in SpecGate gating or state inference.

It shows the minimal shape of a complete Change:

- `proposal.md`: Intent / Scope / Impact / Risks
- `design.md`: Architecture / Technical Approach
- `tasks.md`: Checkable tasks
- `specs/example/spec.md`: Requirements + Scenario

To create a real Change, use `/sg-propose <name>` or `sg_propose`.
