# sp-skill-dispatching-parallel-agents

## 何时使用

同一波里有两个以上互不依赖、都标记了 `parallel` 的任务时。

## 方法

1. 先确认任务真的独立：不同文件、不同模块、无共享状态。
2. 每个任务一个独立 worktree / 分支，互不 checkout。
3. 并行执行实现与测试；**合并串行**，按任务 id 顺序。
4. 合并前校验分支 HEAD 等于预期 commit，防止并发移动。
5. 冲突不自动解决：任务判失败，保留分支，交给人或重试。
6. 整波结束后再跑一次全量回归；失败则整波回退。

## 检查清单

- [ ] 任务之间没有文件交集
- [ ] 每个任务独立 worktree
- [ ] 合并是串行的
- [ ] 冲突时没有强行合并
- [ ] 波结束有全量回归

## 反模式

- 并行任务共用同一个工作目录
- 两个任务同时往 integration 合并
- 冲突时选“我们的版本”继续
