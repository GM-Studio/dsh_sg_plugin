# 行为要求

1. 默认 Java/Vue 模板使用 Element Plus，提供响应式导航、统计、任务 CRUD、忙碌与错误反馈。
2. 初始化记录测试、静态检查、格式检查为未执行，不将模板历史验收等同于当前项目完成。
3. 验证在 Windows/Linux 检查进程及持久环境变量、PATH、常见安装目录与项目工具链，匹配平台可执行文件后验证版本；无效候选继续扫描。扫描有深度与数量边界。
4. 缺失 JDK/Maven 时先通过宿主对话框询问自定义安装目录或可执行文件。空路径走项目内自动安装；取消立即终止；禁用安装时明确阻塞。无交互宿主支持环境变量和工具参数。
5. 自动安装支持默认 JDK 8 与现代预设，按下载内容格式正确解压 Maven。下载/解压失败保留失败证据，不声称可用。
6. 每次验证用独立运行目录记录命令、参数、cwd、时间、退出码及完整日志。所有必需阶段列明通过、失败或未执行；成功、失败、阻塞、取消均同步初始化报告，不能残留成功状态。
7. 运行时检查真实健康、创建、读取、更新、删除、正常重启后的持久化。失败不能产生 SMOKE_PASSED。
