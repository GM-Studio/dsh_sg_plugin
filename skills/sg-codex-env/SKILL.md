# SpecGate 环境准备

环境准备仅在 Codex 会话内执行。先确认业务项目；存量项目读取真实配置，新项目收集用户的 JDK/Spring Boot 和 Vue/React 选择，不能代选默认值。没有技术栈时只诊断或收集选择，不全量安装。

1. 调用 `sg_env_check`，新项目显式传入 `preset`、`frontend`；存量项目读取自身配置。说明可复用、缺失、不兼容组件及拟安装版本、来源、位置。
2. 只请求预检时返回结果，不下载、不写配置。需要补齐时调用 `sg_env_prepare`，遵守可信安装表单与宿主权限。默认国内镜像，官方/自定义源须显式选择。参数、模型自述或聊天同意不能伪造服务端安装回执。
3. `ENV_HOST_INSTALL_REQUIRED` 表示基础组件需原生命令。由 Codex 在当前会话内探测平台和已有包管理器，展示操作，在已有授权及正常宿主权限审批范围内执行。Linux 可通过 apt 安装 Git，Windows 可通过 winget 安装 Git；不提供外部安装脚本、不关闭安全策略、不绕过沙箱。
4. 安装后重新 `sg_env_check`，缺项、取消、权限拒绝、校验错误或探测失败均保持阻塞，说明原因和重试方式。安装命令成功不等于环境通过。

默认只补齐当前技术栈，例如 Java 17 + Vue 不安装 JDK 8/21。复用已有工具与用户目录缓存，不覆盖全局 JAVA_HOME、PATH、npm/Maven 镜像。前端依赖按项目锁文件安装，使用进程范围 npmmirror 和临时 Maven settings；普通插件用户不安装源码仓库开发依赖。固定归档版本并验证可信 checksum，清理属于当前运行的临时目录。

Node 缺失而 MCP 未启动时，由已加载 Skill 指导 Codex 使用会话内本机命令探测、下载与校验固定 Node 版本，安装到用户目录并真实验证，然后重连 MCP。不能依赖未启动 MCP 修复自身；无法恢复就报告阻塞，不转到会话外脚本。

环境检查区分工具链、Codex 能力/认证、SpecGate 连接、项目基线与业务验证。优先复用当前宿主，工作流确需独立 CLI 时再补齐；缺少认证说明人工步骤，不复制登录凭据。版本探测成功不能冒充原生子代理、审批或完整交付通过。

用户只请求环境准备时，完成后停止，不生成项目或开发。被项目或需求入口调用时交回真实结果，复用原技术栈选择。
