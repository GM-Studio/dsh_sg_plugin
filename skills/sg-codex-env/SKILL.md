# 环境检查

对已绑定项目调用 `sg_env_check`，复用已有安装并报告实际版本、路径、不兼容项和缺项。检查必须有界、跨平台，不能因只读请求下载、安装或写入环境配置。

只请求检查时在结果后停止。需要补齐时调用 `sg_env_prepare`，先展示确切版本、来源、校验、位置与权限并经可信宿主表单确认；不得把工具参数或模型陈述当批准。拒绝、取消、下载或复验失败保持阻塞。宿主原生安装缺项按正常权限批准处理，不运行历史外部安装脚本。工具版本通过不等于项目基线、业务测试或原生 AI 会话通过。安装后真实重查并返回原任务，保留用户技术栈选择，不修改全局配置。
