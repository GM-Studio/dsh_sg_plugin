# 环境检查

对已绑定项目调用 `sg_env_check`，复用已有安装并报告实际版本、路径、不兼容项和缺项。检查必须有界、跨平台，不能因只读请求下载、安装或写入环境配置。

Core v1 不提供 `sg_env_prepare` 自动安装入口。若缺少必需工具，保持环境门禁阻塞，并说明可供用户或其授权环境维护者处理的具体缺项；处理后重新真实探测。工具版本通过不等于项目基线、业务测试或原生 AI 会话通过。用户只请求环境检查时，在报告结果后停止。
