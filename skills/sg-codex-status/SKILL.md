# SpecGate 项目信息与状态（只读）

调用 `sg_status`，中文汇总业务项目路径、技术栈、环境检查与缺项、项目基线、Change/WorkItem 阶段、待审批、最近验证/交付和可采取的下一步。

只读查询不安装、不绑定、不创建配置、不初始化、不修复、不恢复任务、不审批。不构造会创建目录的控制面 runtime；“现在什么情况”不构成其他操作授权。

项目未绑定、MCP 未连接或证据缺失时，说明可读事实和未知项，不为查询先修复。历史通过标明时间、提交和范围，不冒充当前通过。环境就绪、基线就绪、任务通过、交付接受分别报告。

可建议环境 `$sg-codex-env`、项目 `$sg-codex-project`、开发/控制/验收 `$sg-codex-change`，等待实际操作请求再执行。
