- 默认生成代码/文档后自动启动多 agent，默认宽松模式，保留仅生成开关；原六项默认全关规则被替代。

- 无多 agent 服务时降级主 agent 串行执行；不能用确定性扫描或伪造报告冒充主 agent 代码审查。
- 默认模式 lenient；strict 显式选择；generateOnly 只生成并标注未验证，不生成成功验证归档。

## 功能需求
- 默认 sg-init 只接受完全空目标目录：.git、零字节文件、空子目录亦拒绝；不覆盖已有内容。此规则针对生成目标，不是源码仓库。
- 生成前后端分离 monorepo，前端 Vue3 + TypeScript + Vite + npm，Node 仅用于工具链。稳定版本明确锁定，Node 仍受支持的 LTS，无浮动 latest。
- 后端 Java8 + Spring Boot2.7.18 + Maven；任务列表、新增、编辑、删除，前端调用真实 /api/tasks API，H2 文件持久化，重启保留；无登录。
- 输入校验、错误反馈、端口可配置、开发代理；前后端独立构建与启动。
- 始终生成完整代码、启动/构建/验证文档。

## 非功能与可选执行
- Windows、Linux、macOS 兼容的启动与验证入口。
- 默认宽松自动多 agent；strict 显式完整验证，generateOnly 只生成。旧 execution 为附加兼容开关，工具链安装不隐式授权。
- 关闭跳过执行且标注未执行/未验证；开启失败必须报告，不得宣称验证通过。
- 执行依赖、开关名称和依赖下载边界在详细设计明确；允许显式开启后下载依赖及安装工具链。
- 初始化参数/确认/目标冲突在生成前拒绝；生成后运行或权限失败保留完整代码和失败报告，不伪造归档成功。
- 披露 Java8/Spring Boot2.7.18 维护安全风险，不擅自升级。
