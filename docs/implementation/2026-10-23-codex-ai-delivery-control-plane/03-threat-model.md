# 威胁模型

- 日期：2026-10-23
- 状态：**设计基线**
- 方法：按资产、信任边界、威胁、控制与验证证据组织；不把设计意图当作已通过验证。

## 1. 关键资产

- 用户身份、设备、会话与 TOTP 状态；
- Worker 令牌与项目白名单；
- Decision 的完整性、版本绑定和幂等性；
- artifactHash 与交付记录；
- 审计链和保留数据；
- 飞书/钉钉 Webhook 与通知内容；
- 云端数据库和备份。

## 2. 信任边界

1. 浏览器与云端 WebUI；
2. 反向代理与云端应用；
3. 云端与本地 Worker；
4. Worker 与本地 Codex/仓库；
5. 云端与飞书/钉钉；
6. 应用与 MySQL；
7. 运维人员与备份/日志。

## 3. 威胁与控制

| --- | -------------------- | -------------------------- | ------------------------------------------------------------- | ------------------ |
| T01 | 消息链接被转发       | 未授权查看或决策           | 短时效 nonce、不建立会话、登录+TOTP、服务端授权               | AC02 负向测试      |
| T02 | Session 劫持         | 冒用已登录用户             | Secure/HttpOnly/SameSite Cookie、短 TTL、撤销、设备绑定、CSRF | 会话与重启测试     |
| T03 | TOTP 重放            | 绕过 step-up               | 当前操作 nonce、时间窗、使用记录、限流                        | AC03 重放测试      |
| T04 | 设备撤销后旧会话继续 | 失去控制的设备继续操作     | 会话绑定设备、撤销级联失效、每次请求校验                      | M2 负向测试        |
| T05 | Worker 令牌泄露      | 越权领取或应用任务         | 独立令牌、可撤销、项目白名单、短期租约、来源校验              | M3 越权测试        |
| T06 | 项目白名单绕过       | 跨项目读取或写入           | Worker 与项目绑定、服务端二次校验、禁止客户端自报授权         | AC11/AC12          |
| T07 | 任意 shell 下发      | 本地命令执行               | 类型化命令、参数白名单、拒绝任意 shell、审计                  | M3-T06 测试        |
| T08 | Webhook 泄露         | 通知伪造或骚扰             | 密钥仅服务端保存、日志脱敏、轮换、最小权限                    | 通知脱敏测试       |
| T09 | artifact 替换        | 批准了错误制品             | 创建 Attention 时冻结 hash、应用前复验、变化即 STALE          | AC04/AC16          |
| T10 | 决策重放             | 重复恢复或重复交付         | 幂等键、唯一约束、状态机、Worker 应用账本                     | AC05 测试          |
| T11 | 审计链篡改           | 无法追责                   | 追加式写入、哈希链、校验失败即拒绝、备份                      | 审计损坏测试       |
| T12 | MySQL 备份泄露       | 身份和决策数据泄露         | 加密备份、最小权限、恢复演练、保留期                          | 运维演练记录       |
| T13 | Host/Origin 伪造     | CSRF、缓存投毒、开放重定向 | 严格 Host/Origin 校验、可信代理配置、Secure Cookie            | AC15 测试          |
| T14 | 断线误完成           | 人工以为任务已执行         | 区分 RECORDED/PENDING_APPLY/APPLIED、心跳、租约、对账         | AC06/AC09          |
| T15 | 未授权项目元数据泄露 | 暴露客户或业务信息         | 项目级权限、响应裁剪、通知最小化                              | AC10/AC11          |
| T16 | 前端持有密钥         | 浏览器侧泄露               | 密钥只在服务端/本地，前端不存储管理凭证                       | 代码审查与响应测试 |
| T17 | 远程模式误配置       | 管理端口裸奔               | 远程模式启动门禁、HTTPS、可信代理、拒绝不安全默认             | AC15               |
| T18 | 审计或通知日志注入   | 伪造记录或泄露             | 结构化日志、字段白名单、长度限制、脱敏                        | 负向测试           |

## 4. 高风险场景的失败语义

- 认证失败：拒绝并审计，不返回可枚举的账号信息；
- step-up 失败：拒绝操作并记录原因，不消费业务状态；
- artifact 变化：旧 Decision 进入 `STALE`，生成新 Attention；
- Worker 离线：Decision 记录为 `PENDING_APPLY`，不宣称已应用；
- 通知失败：记录失败并重试，不阻塞 Attention 生命周期；
- 脱敏失败：fail closed，不发送原始内容；
- 审计损坏：显式失败，不静默修复或跳过。

## 5. 远程部署安全门禁

远程模式必须同时满足：

- 显式启用远程模式；
- HTTPS 或可信代理提供的 HTTPS；
- Secure、HttpOnly、SameSite Cookie；
- 严格 Host/Origin 校验；
- 可信代理列表明确配置；
- 管理端口不直接暴露公网；
- 不满足条件时拒绝启动。

## 6. 验证状态

- 威胁模型：**设计完成，待评审**；
- 自动化负向测试：**尚未全部执行**；
- 真实渗透测试：**NOT_RUN**；
- 真实云环境验证：**NOT_RUN**；
- 备份恢复演练：**NOT_RUN**。

## 7. 残余风险

- 单人团队可能缺少独立安全评审；
- 飞书/钉钉 Webhook 的可用性与密钥轮换依赖外部平台；
- 本地 Worker 所在主机的安全仍由本地环境负责；
- 云服务商、反向代理和 MySQL 的配置错误仍可能导致暴露；
- 本威胁模型不能替代上线前的实际安全测试。
