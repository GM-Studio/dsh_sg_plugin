# 数据分类与边界

- 日期：2026-10-23
- 状态：**设计基线**
- 适用范围：一人团队的 AI 交付控制面，云端 WebUI/控制面 + 本地主动出站 Worker。

## 1. 数据驻留原则

1. 云端只保存协调交付所需的最小元数据；
2. 源码、原始日志、完整 diff 和凭证默认留在本地；
3. 写入数据库前脱敏，发送通知前再次脱敏；
4. 脱敏失败时 fail closed；
5. 前端、通知和日志不得成为绕过数据边界的旁路。

## 2. 数据分类

| 分类            | 示例                                                           | 默认驻留      | 云端可保存       | 通知可携带             | 备注                                    |
| --------------- | -------------------------------------------------------------- | ------------- | ---------------- | ---------------------- | --------------------------------------- |
| 身份与认证      | 用户 ID、设备 ID、会话元数据、TOTP 注册状态                    | 云端          | 是（仅必要字段） | 否                     | 不保存明文密码、TOTP 种子或会话令牌原文 |
| 项目元数据      | 项目名、项目 ID、默认 Worker、通知策略                         | 云端          | 是               | 项目名可               | 不含仓库绝对路径                        |
| WorkItem 元数据 | 标题、范围摘要、优先级、预算、状态、版本                       | 云端          | 是               | 标题、风险、截止时间可 | 不保存完整客户资料                      |
| Run 元数据      | runId、sessionId、开始/结束时间、用量、结果                    | 云端          | 是               | 仅必要摘要             | sessionId 不得暴露给未授权方            |
| Attention       | 原因、问题、风险、证据摘要、动作、过期时间、artifactHash       | 云端          | 是               | 脱敏摘要可             | 链接只定位 Attention                    |
| Decision        | 动作、actor、device、authLevel、版本、artifactHash、幂等键摘要 | 云端          | 是               | 结果可                 | 必须可审计、不可静默覆盖                |
| 执行事件        | 离散事件类型、时间、脱敏摘要、correlationId                    | 云端          | 是               | 有限事件可             | 默认保留 7 天                           |
| 通知投递        | 渠道、接收方标识、尝试次数、结果、错误分类                     | 云端          | 是               | 否                     | 默认保留 30 天                          |
| 交付元数据      | Delivery ID、artifactHash、验证摘要、验收状态                  | 云端          | 是               | 结果可                 | AI 不能最终签字                         |
| 审计日志        | 认证、授权、决策、配置变更、删除操作                           | 云端          | 是               | 否                     | 默认保留 1 年，追加式                   |
| 源码与 diff     | 仓库文件、补丁、完整 diff                                      | 本地          | 否               | 否                     | 仅可上传摘要或哈希                      |
| 原始日志        | 测试完整输出、构建日志、堆栈原文                               | 本地          | 否               | 否                     | 云端只接收有界、脱敏摘要                |
| 凭证与密钥      | Codex 凭证、SSH key、数据库密码、Webhook secret                | 本地/密钥管理 | 否               | 否                     | 永不进入云端业务表或日志                |
| 模型内部内容    | 思维链、逐 token 输出、内部推理                                | 不持久化      | 否               | 否                     | 不进入时间线或通知                      |
| 本地路径        | 绝对路径、用户名、主机目录结构                                 | 本地          | 否               | 否                     | 必要时仅保留不可逆标识                  |

## 3. 字段级规则

### 3.1 允许云端持久化

- `projectId`、`projectName`；
- `workItemId`、`runId`、`attentionId`、`decisionId`、`deliveryId`；
- `workItemVersion`、`artifactHash`；
- 风险等级、状态、时间、预算使用量；
- 脱敏后的短摘要；
- 认证与授权的审计元数据；
- Worker 心跳、租约和项目白名单标识。

### 3.2 禁止云端持久化

- 仓库根目录、工作树路径和本机绝对路径；
- 环境变量值；
- 原始 Authorization、Cookie、Webhook URL；
- 密码、TOTP 种子、恢复码、私钥；
- 完整源码、补丁、测试日志、构建日志；
- 客户名称，除非明确脱敏或获准作为项目元数据；
- 思维链和逐 token 输出。

## 4. 数据流边界

```text
本地 Codex/Worker
  -> 本地脱敏与摘要
  -> 主动出站到云端
  -> 云端校验、最小化持久化
  -> Attention/Decision/Audit
  -> 出站通知到飞书/钉钉
  -> 人通过浏览器登录云端查看与决策
```

禁止路径：

- 云端主动连接本地仓库或本地管理端口；
- 通知携带可直接建立会话的凭证；
- 前端持有 Codex、SSH、数据库或 Worker 密钥；
- 为调试方便把原始日志整体上传云端。

## 5. 保留与删除

| 数据          | 默认保留期 | 可配置 | 删除要求           |
| ------------- | ---------- | ------ | ------------------ |
| 执行事件      | 7 天       | 是     | 记录删除审计       |
| 通知投递      | 30 天      | 是     | 记录删除审计       |
| Decision      | 1 年       | 是     | 不得静默覆盖       |
| Audit         | 1 年       | 是     | 追加删除审计       |
| 会话/配对令牌 | 短 TTL     | 是     | 过期即失效         |
| 备份          | 按运维策略 | 是     | 加密并记录恢复演练 |

## 6. 验证要求

- AC10：注入源码、密钥、绝对路径和客户名后，云端持久化、通知和时间线均不出现禁止字段；
- 脱敏失败必须拒绝发送和写入；
- 日志不得出现 Webhook 密钥、会话令牌或 TOTP；
- 数据导出必须按权限裁剪；
- 备份文件必须视为高敏感数据并加密。

## 7. 未决与边界

- 客户名称是否可作为项目名的一部分，需要在实际接入时明确配置；
- 脱敏规则不能保证识别所有业务敏感词，因此需要项目级补充规则；
- 本文件是设计门禁，不代表已通过 AC10 自动化验证。
